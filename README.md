# Jamii Digital
Building digitally robust & resilient communities.

Free, open, privacy-first digital skills training: a digital skills lab for elders, AI lessons, cyber labs, an afterschool Makers Club, employable skills, puzzles, and a Python Academy. Nothing is collected: learners use a nickname and progress stays on their own device.

- Site: `index.html` (single file, no build step)
- K-12 Teacher-AI harness (open source, MIT): `harness/`

Published with GitHub Pages from the `main` branch, root folder.
